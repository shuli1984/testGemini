# Go-CMS-i18n

[English](README.md) | [中文](README.zh.md) | [日本語](README.ja.md)

A lightweight, file-based CMS with internationalization (i18n) support, built in Go. This project was entirely generated by Gemini.

## Project Overview

Go-CMS-i18n is a simple content management system designed for ease of use and multilingual content. It features an admin panel for managing pages, settings, and translations. The frontend is designed to be clean, modern, and easily customizable.

## Features

* **Page Management:** Create, edit, and delete pages.
* **Admin Panel:** A secure admin area to manage site content and settings.
* **Internationalization (i18n):** Supports multiple languages for content, with JSON-based translation files.
* **Configurable Homepage Carousel:** Dynamically select which pages are featured in the homepage carousel directly from the admin panel.
* **Automatic Translation:** Integrated with Google Cloud Translation, DeepL, and a mock translator to easily translate content between languages.
* **Maintenance Mode:** Easily put the site into maintenance mode for all non-admin users.
* **File-Based:** Uses a local SQLite database file for data persistence.

## Prerequisites

* **Go:** Version 1.18 or higher. Download from [golang.org](https://golang.org/dl/).
* **Git:** (Optional) For cloning the repository.

## Getting Started

### 1. Clone the Repository

```bash
git clone <repository_url>
cd <project_directory>
```

### 2. Set Up Environment Variables

This project uses a `.env` file for sensitive keys and local configuration.

1. **Create `.env` file:** In the project root, create a file named `.env`.
2. **Add variables:** Populate the file with the following. Generate strong, random values for `SESSION_KEY` and `CSRF_KEY`.

    ```bash
    SESSION_KEY=your_long_random_session_key_here_at_least_32_bytes
    CSRF_KEY=your_long_random_csrf_key_here_at_least_32_bytes
    ADMIN_USERNAME=admin
    ADMIN_PASSWORD=password
    TRANSLATOR_API_KEY="your_google_cloud_api_key_here"
    ```

    * **Note:** The `.env` file is listed in `.gitignore` and should never be committed to version control.

### 3. Install Dependencies

Download the necessary Go modules.

```bash
go mod tidy
```

### 4. Run the Application (Development)

This command will start the web server for development.

```bash
go run ./cmd/web
```

The application will listen on the address specified in `config.yml` (default: `:8080`).

### 5. Build the Application (Production)

To build a production executable, run the build script.

**Windows:**

```bash
build.bat
```

**Linux/macOS:**

```bash
go build -o bin/main cmd/web/main.go
```

This will create an executable file in the `bin/` directory.

## Configuration

Application behavior can be configured via `config.yml` and environment variables (which take precedence).

### General Configuration

**`config.yml`:**

```yaml
server:
  addr: ":8080"
  timezone: "UTC"
i18n:
  default_language: "en"
```

### Homepage Carousel

The homepage carousel can be configured from the admin panel:

1. Log in to `/admin`.
2. Navigate to **Settings**.
3. In the **Homepage Carousel** section, you can drag and drop pages from "Available Pages" to "Selected Pages" to feature them on the homepage.

### Translation Service

Configure the translation service in `config.yml` or via environment variables.

**`config.yml`:**

```yaml
translator:
  type: "mock" # "google", "deepl", or "mock"
  api_key: "YOUR_API_KEY_HERE"
```

**Environment Variables:**

```bash
TRANSLATOR_TYPE="google"
TRANSLATOR_API_KEY="YOUR_API_KEY_HERE"
```

* **`mock`:** Default translator for development. No external API calls.
* **`google`:** Uses Google Cloud Translation API. Requires a valid API key.
* **`deepl`:** Uses DeepL API. Requires a valid API key.

### Maintenance Mode

Enable or disable site maintenance mode from the **Settings** page in the admin panel. When enabled, only logged-in administrators can browse the site.
